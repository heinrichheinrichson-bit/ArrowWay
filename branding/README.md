# arrow.joy branding

The butterfly is constructed from eleven single-headed arrow paths. SVG sources are generated by `python tools/generate_brand_assets.py`; regenerate PNG exports with Godot using `--headless --path . --script res://tools/render_brand_assets.gd`.

`mark.svg` is the transparent in-app emblem. `icon.png` is the desktop and legacy Android icon. Adaptive Android icons use the separate transparent foreground and solid navy background; their symbol fits within the central safe area. A white monochrome layer supports themed Android launcher icons.

The home wordmark is rendered as text so it stays sharp at all sizes, with a pink period. The display name is arrow.joy. Keep Android package `com.example.arrowway` and custom data directory `ArrowWay` stable to retain update compatibility and progress.
